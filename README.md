# E-commerce Sales Analysis Dashboard

## Project Overview
This project focuses on analyzing e-commerce sales data using Microsoft Power BI. The dashboard provides insights into sales performance, customer behavior, product categories, and city-wise sales.

## Objectives
- Analyze overall sales performance.
- Identify top-performing product categories.
- Understand monthly sales trends.
- Analyze city-wise and gender-wise sales.
- Create an interactive dashboard for business insights.

## Tools & Technologies
- Microsoft Power BI
- DAX
- Data Cleaning
- Data Visualization

## Key Performance Indicators (KPIs)
- Total Sales
- Total Orders
- Total Customers
- Total Quantity
- Average Order Value

## Dashboard Features
- Sales by Category
- Monthly Sales Trend
- Sales by City
- Gender-wise Sales Analysis
- Interactive Date, Category, and City Filters

## Dataset
The dataset contains e-commerce transaction information, including order dates, customers, product categories, cities, gender, quantity, and sales.

## Project Files
- `cleaned_sales_dataset.csv` — Cleaned dataset
- `Ecommerce_Sales_Analysis.pbix` — Power BI dashboard
- `README.md` — Project documentation

## Conclusion
This dashboard helps analyze e-commerce sales performance and identify useful business trends through interactive visualizations.
